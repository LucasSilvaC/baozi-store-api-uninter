# Evidências da coleção Postman

`00-postman-runner-resumo.jpg` registra o resultado do Collection Runner. As imagens `01` a `12` são capturas individuais das respostas no Postman Web, executadas com o Desktop Agent local e o ambiente `Baozi Store - local`. Esses arquivos ficam na cópia local e no PDF de entrega; não são publicados neste repositório público porque mostram dados pessoais.

As doze capturas cobrem os três POSTs, os três GETs gerais, os três GETs por ID e os três DELETEs. Os POSTs retornaram `201`, os GETs `200` e os DELETEs `204`.

O relatório final incorpora as doze capturas na seção 4.1. Ele também registra a execução Newman 6.2.3, com 15 requisições e 27 verificações automatizadas aprovadas.
